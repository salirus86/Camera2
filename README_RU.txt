УМНЫЙ РАДАР — исходный Android-проект

Что умеет:
- Показывает изображение с задней камеры.
- В реальном времени ищет людей и транспорт COCO-моделью EfficientDet-Lite0.
- Выводит рамки и счётчики: люди / транспорт.
- Классы транспорта: автомобиль, грузовик, автобус, мотоцикл, велосипед.

Важно:
- Это исходный проект, а не готовый APK.
- При первом запуске приложению нужен интернет, чтобы загрузить модель распознавания.
  После загрузки модель хранится в памяти приложения.
- Распознавание может ошибаться; это вспомогательный инструмент, не средство безопасности,
  слежения или идентификации личности.
- Камера работает локально; кадры не отправляются на сервер приложением.
- Для установки нужно собрать APK в Android Studio либо через GitHub Actions.

Сборка в Android Studio:
1. Распакуйте архив.
2. Откройте папку UmnyRadar в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Выберите Build -> Build Bundle(s) / APK(s) -> Build APK(s).
5. APK появится в app/build/outputs/apk/debug/app-debug.apk.

Сборка через GitHub Actions:
1. Создайте новый репозиторий GitHub и загрузите туда содержимое папки.
2. Откройте вкладку Actions.
3. Запустите workflow "Build Android APK" (Run workflow).
4. Скачайте artifact "UmnyRadar-debug-apk".

Совместимость:
- Минимальная версия Android: 8.0 (API 26).
- Для Honor X8c ожидается совместимость при актуальной прошивке Android.
- На телефоне нужно разрешить доступ к камере.
